# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to this project!

We welcome:
- **All contributions**: Any constructive improvements to the code or repository.
- **Bug reports**: Informing us of any bugs or issues you encounter.
- **Bug fixes**: Submitting pull requests to address and fix bugs.
- **Documentation improvements**: Enhancing or clarifying existing documentation.
- **Enhancements**: New features and calculation options.
- **Ideas**: Brainstorming and proposing suggestions for future development.

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.
