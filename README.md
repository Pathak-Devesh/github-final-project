## Simple Interest Calculator

A Bash script application that calculates simple interest given principal amount, annual rate of interest, and time period in years.

### Input Parameters:
- **Principal (`p`)**: The initial principal amount of money invested or borrowed.
- **Rate of interest (`r`)**: The annual rate of interest (percentage per year).
- **Time period (`t`)**: The time period in years for which the money is borrowed or invested.

### Simple Interest Formula:
```
Simple Interest = (Principal × Rate of interest × Time period) / 100
```
In variable terms:
```
simple interest = (p * t * r) / 100
```

### Example Calculation:
```
Input:
   Principal (p) = 1000
   Rate of interest (r) = 5
   Time period in years (t) = 2

Output:
   simple interest = (1000 * 5 * 2) / 100 = 100
```
